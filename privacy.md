# Политика конфиденциальности — «Мои счётчики»

Дата актуализации: 02.11.2026. Версия приложения: 2.0.0, пакет `ru.egor.meters`.

«Мои счётчики» — локальное offline-first приложение для хранения показаний бытовых счётчиков.

## Какие данные хранит приложение

На устройстве пользователя могут храниться:

- названия/адреса объектов;
- сведения о счётчиках, серийные номера и необязательные реквизиты;
- история показаний, тарифные зоны, тарифы и сроки поверки;
- фотографии счётчиков, сделанные по явному действию пользователя;
- локальные настройки напоминаний и безопасности;
- заметки и сохранённые пользователем шаблоны получателей;
- отметки о передаче показаний и снимки переданных значений.

## Где хранятся данные

Основные данные хранятся в локальной Room/SQLite базе приложения. Фотографии сохраняются в каталоге приложения (`external-files/Pictures`) и не требуют доступа к общей галерее.

Приложение не содержит обязательного аккаунта, облачной синхронизации или собственного сервера. Разрешение `android.permission.INTERNET` не запрашивается.

## Резервные копии, CSV и передача показаний

Резервная копия и CSV создаются только по явному действию пользователя. Место сохранения выбирается через системный диалог Android. Текст показаний можно скопировать или передать через стандартное меню Android Share. Автоматической отправки данных в УК/РСО нет.

## Фотографии

Для съёмки приложение запускает системное/установленное приложение камеры через Android Intent и выдаёт ему временный доступ только к подготовленному URI файла приложения. Собственное разрешение `CAMERA` приложению для этого сценария не требуется.

## Уведомления

`POST_NOTIFICATIONS` используется только для локальных напоминаний о передаче показаний и поверке. Уведомления можно отключить.

## Блокировка входа

По желанию пользователя приложение может требовать подтверждение системной блокировки устройства. Используется системный Android API; приложение не хранит PIN, пароль или графический ключ пользователя.

## Передача третьим лицам

Само приложение не отправляет пользовательские данные разработчику или третьим лицам. Передача возможна только по явному действию пользователя через выбранное им приложение/место сохранения.


## Распознавание показаний

При использовании распознавания текст обрабатывается на устройстве библиотекой Google ML Kit с включённой моделью. Приложение не отправляет фотографии на сервер распознавания. Результат требуется проверить перед сохранением.

## Реклама и аналитика

Приложение не содержит рекламных модулей, аналитики поведения или регистрации. Разработчик не получает показания, адреса и фотографии через приложение. Разрешения доступа к геолокации, контактам и общей медиатеке не запрашиваются.

## Срок хранения и удаление

Данные остаются на устройстве до их удаления пользователем. Отдельные адреса, счётчики и показания можно удалить через интерфейс с подтверждением. Для удаления всех внутренних данных можно очистить хранилище приложения средствами Android или удалить приложение. Это необратимое действие; перед ним при необходимости сохраните резервную копию.

Экспортированные резервные копии, CSV и данные, переданные в другое приложение, необходимо удалять отдельно в выбранном месте хранения или у получателя. Приложение не может удалить уже переданные копии. Резервные копии и CSV могут содержать введённые адреса и реквизиты; храните их в месте с подходящим доступом. Файл резервной копии не следует считать зашифрованным.

Автоматическое резервное копирование Android отключено в манифесте (`allowBackup=false`). На поведение переноса данных отдельными производителями устройств приложение не даёт гарантий.
